# Klasaipeer · Public Website

This **public** GitHub Pages repository hosts the Klasaipeer public landing page and a self-contained, temporary character design preview.

## Public preview
- Original illustrative student avatar (simple SVG concept, not final character art)
- Appearance, style, school-stage, personality and up to five custom descriptors
- Browser-provided text-to-speech voice previews, volume and pace
- Five planned visual maturity bands
- No account creation, adoption processing, chat backend or persistence

## Privacy boundaries
The public preview does not store or transmit children’s personal data, adoption records, chat conversations, account credentials or guardian approval. The public site must never include secrets, private CORE files, sensitive internal implementation documents or private Academy account data. Any real adoption service must be separately authorized, authenticated and tested.

Klasaipeer adoption is planned to start **only inside an enrolled learner's Academy profile**, and is separate from normal Academy school enrollment. This public website is for exploration, not enrollment.

## Status
Public landing: static prototype. Production avatar rendering, companion chat, protected adoption and lifelong memory services: not implemented here.
